Search order

Sources are tried top to bottom. The first confident match is acted on (download, open free gate, or add to cart).

    DJDelivery

    I couldn't inspect DJDelivery while building this, so it's configured here instead of hard-coded. Fastest path: turn on Discovery below, search for one track on DJDelivery and download it, then use the request log to fill in the search URL and the download link. If its search returns JSON, paste a response into Auto-map JSON.

    Test DJDelivery search

    Auto-map JSON

    Paste one search response from DJDelivery (DevTools → Network → the search request → Response). This fills in the JSON paths.

    Discovery log

    With discovery on, requests made by DJDelivery pages are logged here: method, URL, status and type only. No bodies, cookies or headers are stored.
